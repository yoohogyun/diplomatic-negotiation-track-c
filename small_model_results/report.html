GPT-5.6 Luna with a public-state strategic controller

In a synthetic negotiation grounded in supplied diplomatic sentences, Luna realizes utterances while a local controller selects queries, signals, concessions, and ratification. The controller uses action costs and beliefs updated from opponent responses.

On the same existing 64 conditions, the learned policy achieves 92.5% of Sol medium net utility. Planning with the declared public transition rules differs from Sol by +0.01942. Replaying 200 trajectories reproduced the saved planning result.

Sol action selection averages 3.429 calls, 4184.8 tokens, and $0.02363 per negotiation. Both local controllers make zero model calls for action selection. These figures exclude shared utterance-bank generation/interpretation and teacher/training costs, so they do not measure an end-to-end service cost reduction.

Real documents ground the expressions and context; utilities, types, and responses are synthetic. The planner knows the declared opponent response model exactly. It is a strong benchmark under known rules, not evidence of general diplomatic performance or a new algorithm. Luna alone uses none while Sol uses medium reasoning, so this is not an isolated model-size comparison. Evaluation uses a fixed model-generated/interpreted bank, not newly generated online dialogue.

The paper investigates whether separating strategic control over public beliefs and action costs can improve negotiation utility and reduce strategy-selection model calls for a smaller language model. PPO is a required course baseline and one controller implementation, not a claimed new algorithm.
