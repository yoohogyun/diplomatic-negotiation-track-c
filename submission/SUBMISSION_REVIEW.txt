과제 제출 검토 — 2026-10-12

판정: 연구 내용과 필수 실험을 갖춘 과제 제출 원고이다. 실제 학회 투고/accept는 과제 완료 조건이 아니다(공통 가이드 22쪽). 저자·기여·실제 팀원 실행·접근 권한·제출은 사용자가 마무리해야 하므로 '모든 절차가 이미 완료'된 상태라고 표현하지 않는다.

채점 기준과 증거
환경/정식화 25점: 숨은 유형을 제외한 31차원 관측, 베이즈 갱신, 11개 행동, 양측 수락, 5결정 종료, 보상식과 비용. 본문 Method, Appendix A, pilot/env.py, study/env.py. 실제 문서12개/6사건군과 유형별 검증24경로를 합성 시나리오와 구별.
학습/실험 25점: Random/Heuristic/Bandit/PPO, 기본학습3seed, 동일 상호작용102400, 할인율/entropy/주요 보상 ablation, 믿음mask 및 질문/신호 개입, 규칙민감도. 본문 Table 1/Figure 2, Appendix B/D, 저장모델과 raw. PPO가 휴리스틱보다 낮은 결과를 그대로 설명.
담화/언어분석 30점: 본문 전략 경로 그림과 해석, Appendix C의 성공·실패·양보·철회 6개 에피소드, 실제 합성 발화 인용과 출처, Appendix D의 전이행렬 해석. 기능명만 외교적으로 바꾼 분석이 아님. 발화의 수치/조건/약속 강도가 전이에 영향을 줌.
논문/재현 20점: ACL 원형 유지, 결론까지4쪽, 별도 Limitations/Ethics, 데이터 원논문 포함 참고문헌, 편집소스/그림/체크포인트/오프라인 재현 절차. 부록은 가이드 권장1–2쪽보다 길지만 페이지 제한은 없으므로 형식 위반은 아님.

이번 검토에서 보강한 점
- 본문의 단계별 보상식과 비용 정의.

- 자료/모델 사용에 관한 Ethical Considerations.
- Overleaf 최소 프로젝트와 저자 파일 분리, 기존 README의 '논문 미작성' 상태 수정.

남은 사용자 작업 (새 모델/추가 실험을 요구하는 항목이 아님)
1. authors.tex: 이름/소속/학번. 영문 표기 사용; main.tex의 review를 final로 바꾸면 실명이 보임.
2. TEAM_RECORD.txt: 실제 역할과 다른 팀원의 실행자/날짜/commit/결과 기록. 자동 검증은 다른 팀원의 실제 수행을 대체하지 않음.
3. GitHub 비공개 저장소에 평가자/팀원 접근 권한 부여.
4. 최종 PDF/저장소 주소를 공지된 과제 제출처에 직접 제출.

학회 전망은 별개: 새 알고리즘 제안이 아니라 통제된 환경에서의 전략 분리/증류/담화 분석이다. 고정 발화와 알려진 합성 규칙, 두 평가 사건군의 범위 때문에 accept를 보장하지 않는다. 과제는 성능 향상 크기보다 설계·검증·분석의 타당성을 평가한다(공통 가이드20쪽).

사람 담화 검토에 관한 구분: 최소6사례 분석은 원고에 작성되어 있다. 가이드의 20턴 검토는 권장이고 62개 별도 라벨링은 필수가 아니다. 현재 분석은 저장로그 기반의 작성·검토이며, 인간 독립 검증/전문가 합의를 수행했다고 주장하지 않는다.
